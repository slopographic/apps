# Glossary: Polish (pl)

Register: informal singular, as Microsoft Office, Google Workspace and Adobe Acrobat do in Polish. Buttons and commands are second-person imperatives («Zapisz», «Otwórz», «Anuluj»); menu titles are nouns («Plik», «Edycja», «Widok», «Pomoc»). In running text address the user as «Ty»; capitalise «Ty / Twoje / Ci» as Google and Microsoft do. Quotes are „polskie”. Keep labels short.
