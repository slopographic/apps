# Glossary: Arabic (ar)

Register: Modern Standard Arabic, right to left. Menu commands use the verbal noun ("حفظ", "فتح", "طباعة"), as Microsoft Office and Acrobat Arabic do; buttons that read as a sentence to the user use the masculine-singular imperative ("افتح التطبيقات", "احتفظ بملفاتي"), and prose addresses the user with masculine singular "ك" ("ملفاتك"), matching shared/i18n/ar.js. Latin brand names stay in Latin script inside the Arabic text.
