Excel (XLSX) to vCard converter

Turn an Excel workbook of contacts into a vCard file. Each row becomes one contact.

Accepts

Excel workbook (.xlsx). Other file types are not converted on this page.

How to convert

  1. Drop an .xlsx file. The first sheet is read, and its first row must hold the column names.
  2. After converting, the status line lists the recognised columns and any column that was not used. Check that the right ones are there.
  3. Download the .vcf file and import it into your contacts app. Each row is one BEGIN:VCARD block.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Is every sheet converted?

No. Only the first sheet is read. Copy the others to the first sheet, or save them as separate workbooks.

Are formulas and formatting read?

The values that Excel shows are used. Formulas are not calculated, and formatting is ignored.
