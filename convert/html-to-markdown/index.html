HTML to Markdown converter

Turn a saved web page, an email template or an HTML export into Markdown for a README, a wiki, notes or a static site.

Accepts

HTML (.html). Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. Headings, paragraphs, bold, italic, links, images, nested and numbered lists, quotes, code blocks (with their language) and tables become their Markdown form.
  2. Scripts, styles and forms are left out. Characters that mean something in Markdown, such as * and _, are escaped so they stay text.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Which Markdown does it write?

CommonMark, with GitHub-style pipe tables and ~~strikethrough~~, which GitHub, GitLab, Obsidian and most editors read.

Can I type or paste instead of a file?

Yes. Type or paste in the box under the converter, and the preview updates as you type.

Are my files uploaded?

No. The conversion runs in your browser, on this device. Your files are not sent to Slopographic or to any other server.
