Line ending converter (LF, CRLF, CR)

Make a text file use Windows (CRLF), Unix (LF) or classic Mac (CR) line endings.

How it works

Every CRLF, LF or CR line break is rewritten as the one you choose. The text itself is not changed.

Your files stay on this device. Nothing is uploaded, and the converter runs entirely in your browser.

Questions

Which line ending should I use?

LF for Linux, macOS and most code. CRLF for Windows tools that expect it.

Will the text change?

Only the line breaks. Characters, spacing and encoding stay as they are.

Are my files uploaded?

No. Every conversion runs in your browser, on this device. Files are not sent to Slopographic or to any other server.
