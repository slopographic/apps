Markdown to PDF converter

Turn README files and notes written in Markdown into a PDF with real pages, selectable text and bookmarks for the headings.

Accepts

Markdown (.md, .markdown). Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. The Markdown is laid out by the Slop Docs engine: headings, lists, quotes, code blocks, bold, italic and code spans. Tables, links and images stay as the Markdown text that was typed.
  2. Text in Arabic, Chinese, Hindi and other writing systems is set with a Noto font for that script, downloaded once after the page asks.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Can I copy the text from the PDF?

Yes. The text is real text, not a picture, so it can be selected and searched.

Which page sizes?

A4 or US Letter, with the font you choose: sans serif, serif or monospaced.

Are my files uploaded?

No. The conversion runs in your browser, on this device. Your files are not sent to Slopographic or to any other server.
