Password protect a PDF

Lock a PDF with a password before you email or share it. The encryption runs on this device, so the file and the password never leave it.

Accepts

PDF documents (.pdf). A PDF that already has a password must have it removed first. Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. Drop the PDF and open Options. Type the password twice.
  2. Untick what readers may not do once the file is open: printing, copying text and pictures, or editing pages, text and comments.
  3. Press Convert. Every string and stream of the PDF is encrypted with AES-256 (the PDF 2.0 standard security handler), and the password fields are cleared.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and neither the file nor the password is sent to Slopographic or to any other server.

Questions

How strong is the encryption?

AES-256 with the PDF 2.0 password hashing, the strongest encryption PDF has. A long password that is not used anywhere else is what keeps the file safe.

Which apps open the protected PDF?

Any current PDF reader: Adobe Acrobat and Reader, Apple Preview, Chrome, Edge, Firefox and the Slop PDF editor ask for the password and open it.

Do the print and copy limits always hold?

Readers that follow the PDF rules, such as Acrobat, Preview and browsers, apply them. They are a request to the reader app, not a lock like the password itself.

What if I forget the password?

The file cannot be opened. There is no recovery: keep a copy of the original PDF or of the password somewhere safe.

Is my PDF or my password uploaded?

No. The PDF is encrypted or decrypted in your browser, on this device. Neither the file nor the password is sent to Slopographic or to any other server, and the password is forgotten after Convert.
