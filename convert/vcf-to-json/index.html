vCard to JSON converter

Turn a .vcf address book into a JSON array with one object for each contact.

Accepts

vCard (.vcf). Other file types are not converted on this page.

How to convert

  1. Drop one or more vCard files (.vcf). The file can hold any number of BEGIN:VCARD blocks.
  2. Choose Convert to JSON. Each contact becomes an object with fields such as fn, name, emails, phones, adr and org.
  3. Download the JSON file and use it in your app. Photos are not included.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

What are the field names?

fn is the full name, name holds given and family, emails and phones are lists of value and types, adr holds addresses, and org, title, url and note are text.

Is this the same data as the Contacts app?

It is read by the same vCard reader that Slop Contacts uses, so the fields match what the app shows.
