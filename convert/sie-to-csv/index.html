SIE to CSV converter

Get the transactions of an SIE file as a plain table for a spreadsheet, a database or your own script.

Accepts

SIE files (.se, .si, .sie): types 1, 2, 3, 4 and 4I. Other file types are not converted on this page.

How to convert

  1. Drop the .se or .si file. The character set is worked out from the file: PC8 (code page 437), UTF-8 or Windows-1252.
  2. Each transaction line becomes a row: series, number, date and text of the voucher, then the account and its name, debit, credit, signed amount, the line’s own date and text, objects (dimension:object) and quantity.
  3. An SIE 1, 2 or 3 file has no vouchers, so its CSV holds the balances per account instead: opening, closing and result for each year in the file.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Will Excel read the amounts as numbers?

Choose comma for an English Excel. For Excel in Swedish, German or another language with a decimal comma, choose semicolon: the amounts are then written 1234,50. The file starts with a BOM so letters such as å, ä and ö show correctly.

Are vouchers that do not balance kept?

Yes. Every line is written, and the Note column says Voucher does not balance, so you can find it.

Is my file uploaded?

No. The file is read by this page in your browser and the result is made on your device. Nothing is sent to Slopographic or to anyone else.
