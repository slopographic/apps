Convert text to UTF-8 (fix garbled characters)

Old Windows programs, Excel exports and subtitle sites still save text in older encodings. Save it once as UTF-8 and every program reads it right.

Accepts

Plain text (.txt), CSV (.csv), SubRip subtitles (SRT) (.srt), WebVTT subtitles (VTT) (.vtt), HTML (.html), XML (.xml), JSON (.json), Markdown (.md). Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. Detect reads UTF-8 and UTF-16 (with or without a byte-order mark) and takes anything else as Western Windows-1252. If the letters still look wrong, choose the file’s encoding: Central European, Cyrillic, Greek, Turkish, Hebrew, Arabic, Thai, Japanese, Chinese or Korean.
  2. The file keeps its name with -utf8 added and its own extension, so a CSV stays a CSV. Tick the UTF-8 mark for Excel and old Notepad.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

How do I know which encoding a file has?

Look at the preview: when the after side shows the right letters, the encoding is right. Try the encoding of the language and country the file came from.

Which files can I fix?

Any text file: TXT, CSV, SRT and VTT subtitles, HTML, XML, JSON, Markdown and the others File convert reads as text.

Are my files uploaded?

No. The conversion runs in your browser, on this device. Your files are not sent to Slopographic or to any other server.
