Markdown to Word (DOCX) converter

Turn Markdown into a Word document you can hand to anyone. Headings use Word's own Heading styles, so the navigation pane works.

Accepts

Markdown (.md, .markdown). Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. The Markdown is read by the Slop Docs engine and written as DOCX by its Word writer: headings, bulleted and numbered lists, quotes, code blocks, bold, italic and code spans.
  2. Tables, links and images stay as the Markdown text that was typed. Open the file in Word, LibreOffice, Google Docs or Slop Docs.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Can I edit it in Word?

Yes. It is an ordinary DOCX with Word's built-in styles.

Which page size?

A4 or US Letter, with the font you choose.

Are my files uploaded?

No. The conversion runs in your browser, on this device. Your files are not sent to Slopographic or to any other server.
