CSV to YAML converter

Turn a table into YAML items: one per row, with the column names as keys.

Accepts

CSV files (.csv), with commas, semicolons, tabs or pipes between the cells. Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. The CSV is read with its quoting rules (RFC 4180); the separator is detected. Each row becomes a record.
  2. The records are then written as YAML. Tick Write plain numbers as JSON numbers in step 1 so numbers are not quoted.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

What if my CSV has no header row?

Untick First row has column names: each row becomes a list of values.

Can I keep the file made in between?

Yes. Open Options and tick Also keep the in-between files: it is listed with the result.

Are my files uploaded?

No. Both steps run in your browser, on this device. Your files are not sent to Slopographic or to any other server.
