Text (TXT) to PDF converter

Turn a .txt file, a log or a letter into a PDF to print or send. The text stays real text that can be searched.

Accepts

Plain text (.txt). Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. Each line of the text becomes a line on the page; long lines wrap. The default font is monospaced, so columns line up; choose sans serif or serif for prose.
  2. Text in Arabic, Chinese, Hindi and other writing systems is set with a Noto font for that script, downloaded once after the page asks.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

What encoding should the file be?

UTF-8, the encoding of almost every text file today. Save an older file as UTF-8 first if its accents come out wrong.

Can I choose the page size?

Yes: A4 or US Letter.

Are my files uploaded?

No. The conversion runs in your browser, on this device. Your files are not sent to Slopographic or to any other server.
