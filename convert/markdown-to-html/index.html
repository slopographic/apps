Markdown to HTML converter

Turn a Markdown document into HTML you can publish or embed. Output is a complete page or a fragment.

How it works

Headings, paragraphs, emphasis, code, links, images, lists, quotes and rules are converted. Raw HTML in the source is shown as text, so the result is safe.

Tables and nested lists are not supported yet.

Your files stay on this device. Nothing is uploaded, and the converter runs entirely in your browser.

Questions

Can I keep raw HTML?

No. Angle brackets are escaped so the output is safe to publish. Write the HTML in a separate file if you need it.

Are links checked?

Only web, mail, fragment and relative links are kept. Anything else, such as javascript:, becomes #.

Are my files uploaded?

No. Every conversion runs in your browser, on this device. Files are not sent to Slopographic or to any other server.
