JSON to TOML converter

Turn a JSON object into TOML: nested objects become [tables], lists of objects become [[arrays of tables]].

Accepts

JSON (.json). Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. The JSON must be an object at the top, since a TOML file is a table of keys. It is written by smol-toml.
  2. TOML has no null, so null values are left out, and the status line says how many.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Will numbers stay numbers?

Yes. Whole numbers are written as integers and the rest as floats.

Can I type or paste instead of a file?

Yes. Type or paste in the box under the converter, and the preview updates as you type.

Are my files uploaded?

No. The conversion runs in your browser, on this device. Your files are not sent to Slopographic or to any other server.
