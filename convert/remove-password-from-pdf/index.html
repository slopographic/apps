Remove the password from a PDF

Tired of typing the password every time? Make a copy of the PDF that opens straight away, on this device.

Accepts

Password-protected PDF documents (.pdf) that use the standard PDF password: RC4, AES-128 or AES-256. Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. Drop the protected PDF, open Options and type the password that opens it. A PDF that opens without a password but blocks printing or copying needs none.
  2. Press Convert. Every string and stream is decrypted and the file is saved again without its encryption. The password field is cleared.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and neither the file nor the password is sent to Slopographic or to any other server.

Questions

Can it remove a password I do not know?

No. You need the password that opens the PDF; this is not a password cracker.

Which encryption does it read?

The standard PDF password handler in every version: RC4 40 and 128-bit, AES-128 and AES-256. PDFs locked to a certificate or a rights-management server cannot be opened.

Are the print and copy limits removed too?

Yes. The copy has no encryption, so readers no longer limit printing, copying or editing.

Is my PDF or my password uploaded?

No. The PDF is encrypted or decrypted in your browser, on this device. Neither the file nor the password is sent to Slopographic or to any other server, and the password is forgotten after Convert.
