YAML to JSON converter

Turn a YAML config into JSON for code, an API or a validator.

Accepts

YAML (.yaml, .yml). Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. The YAML is read by js-yaml; a mistake is reported with its line and column. Anchors and merge keys are resolved.
  2. A file with several documents (separated by ---) becomes a JSON array, one item per document. Dates become ISO text.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Are comments kept?

No. JSON has no comments, so they are left out.

Can I type or paste instead of a file?

Yes. Type or paste in the box under the converter, and the preview updates as you type.

Are my files uploaded?

No. The conversion runs in your browser, on this device. Your files are not sent to Slopographic or to any other server.
