JSON to CSV converter

Flatten a JSON array of objects into a CSV that opens in any spreadsheet.

How it works

Column names come from every key in the array, in the order they first appear. Missing values are blank.

Nested objects and arrays are written as JSON text inside their cell.

Your files stay on this device. Nothing is uploaded, and the converter runs entirely in your browser.

Questions

Why are some cells JSON text?

A CSV cell holds one value, so nested objects and arrays are kept as JSON inside it.

Can I pick the separator?

Yes: comma, semicolon or tab. Use semicolon for spreadsheets set to European number formats.

Are my files uploaded?

No. Every conversion runs in your browser, on this device. Files are not sent to Slopographic or to any other server.
