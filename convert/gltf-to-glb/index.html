glTF to GLB converter

A .gltf often comes with a .bin file and a folder of pictures. A GLB holds all of them in one file that is easy to share.

Accepts

glTF 3D model (.gltf, with its .bin and pictures). Other file types are not converted on this page.

How to convert

  1. Drop the .gltf together with the .bin and picture files it names (select them all at once). Embedded .gltf files need nothing else.
  2. If a buffer is missing, the page names it; a missing picture is listed and left out.
  3. A glTF or GLB compressed with Draco or meshoptimizer, or with KTX2 textures, needs a decoder: it is downloaded once from the Slopographic cdn, checked against its SHA-256, and kept by the browser.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Is anything lost?

Meshes, materials, textures, animations and cameras are kept. Draco or meshoptimizer compression is not: the GLB is written uncompressed, so it can be larger.

My .gltf has a folder of textures. Is that fine?

Yes. Files are found by name, so drop the pictures from the folder together with the .gltf.

Can I go back from GLB to glTF?

Yes. Choose To glTF on the converter: it writes one .gltf file with the data embedded.
