SIE to JSON converter

Get the transactions of an SIE file as JSON for a script, an API or a database import.

Accepts

SIE accounting files (.se, .si, .sie), types 1, 2, 3, 4 and 4I. Other file types are not converted on this page; the File convert hub takes every kind it knows.

How to convert

  1. The SIE file is read first and written as a table, one row per transaction line (voucher, date, account, debit, credit and more). SIE 1 to 3 files give the balances per account instead.
  2. The table then becomes JSON: an array with one object per row, the column names as keys. Tick Write plain numbers as JSON numbers to get amounts as numbers.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Why does it go through CSV?

The route is SIE to CSV, then CSV to JSON. The tile in the middle switches it to go through Excel instead.

Can I keep the file made in between?

Yes. Open Options and tick Also keep the in-between files: it is listed with the result.

Are my files uploaded?

No. Both steps run in your browser, on this device. Your files are not sent to Slopographic or to any other server.
