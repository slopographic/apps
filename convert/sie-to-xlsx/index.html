SIE to Excel (XLSX) converter

An SIE file is the export Swedish accounting programs make for the accountant, the auditor or another program. Turn it into a workbook you can filter, sum and print.

Accepts

SIE files (.se, .si, .sie): types 1, 2, 3, 4 and 4I. Other file types are not converted on this page.

How to convert

  1. Drop the .se or .si file. SIE types 1 to 4 and 4I are read, in the PC8 character set (code page 437) the standard asks for, and in UTF-8 or Windows-1252 when a program wrote those instead.
  2. The workbook has an Info sheet (company, organisation number, program, years, checksum), Vouchers with one row per transaction line, Accounts, and Balances with the opening and closing balance and the result per account and year. Period balances get a Periods sheet.
  3. After converting, the status line gives the counts and the totals, and any note from the reader, such as a voucher that does not balance or balances that do not add up.

Your files stay on this device. Nothing is uploaded: the conversion runs in your browser, and the file is never sent to Slopographic or to any other server.

Questions

Which SIE versions are read?

The SIE file format as described in SIE 4C (2025) and 4B (2008), which describe the same format: types 1, 2, 3, 4 (export) and 4I (import). Older files read the same way.

What happens to added and removed lines?

An added line (#RTRANS) is listed once, marked Added line. A removed line (#BTRANS) is listed with its old amount in the note, and is not counted.

Is the checksum checked?

Yes. When the file has a #KSUMMA checksum it is worked out again, and the Info sheet says whether it matches.

Are dates and amounts real Excel values?

Yes. Dates are Excel dates and amounts are numbers, so sums and filters work. Debit and credit have their own columns, and Amount is signed: debit positive, credit negative.
