CSV to JSON converter

Turn a spreadsheet export or any CSV into a JSON array of objects. The first row supplies the key names.

How it works

The CSV is parsed by RFC 4180 rules, so quoted cells can hold commas, quotes and line breaks. Each row becomes an object.

Values stay text unless you ask for numbers. Turning on numbers only converts values that come back identical, so IDs and leading zeros are safe.

Your files stay on this device. Nothing is uploaded, and the converter runs entirely in your browser.

Questions

What if my CSV uses semicolons?

Leave Separator on Detect, or choose Semicolon. Most European spreadsheet exports use semicolons.

What if the first row has no headers?

Untick "First row has column names" and the result is an array of arrays.

Are my files uploaded?

No. Every conversion runs in your browser, on this device. Files are not sent to Slopographic or to any other server.
